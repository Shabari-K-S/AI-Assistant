# Tactical Holographic UI Aesthetic Rule

When writing or editing UI code (HTML, CSS, React, JSX/TSX, Jetpack Compose):

1. **Aesthetic Invariant:**
   - All interfaces in this project MUST strictly follow the **Tactical Holographic Sci-Fi / Cyberpunk Command Deck** design system.
   - Banned: Plain white screens, generic purple/grey Material themes, bootstrap-like cards, and flat MVP designs.

2. **Color Invariants:**
   - Surfaces must be deep void (`#03070b` / `#06080D` / `#09141d`) with glassmorphic transparency and 1px cyan borders (`rgba(65, 230, 255, 0.14)`).
   - Accents must use Neon Cyan (`#00F2FE`), Electric Blue, Cosmic Purple, Alert Crimson, or Warm Amber based on assistant state.

3. **Typography Invariants:**
   - Headers and HUD tags must use uppercase `Orbitron` with letter spacing (`0.18em+`).
   - Numerical readouts and telemetry must use monospace fonts with cyan text glow.
